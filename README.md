One funny line for the "Make the Judge Laugh in One Line" bounty: a coffee order that ends with the barista handing over her resignation letter instead of a drink. The program writes the line to `entry.txt` and validates the 1–200 character gate itself before writing.

## Run it

```sh
python3 main.py
```
